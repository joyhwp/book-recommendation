Semantic Book Recommender

Recommends books from a natural-language description (e.g., "a story about forgiveness"), with filters for category and emotional tone.

Built by following the freeCodeCamp course Build a Semantic Book Recommender with LLMs by Dr. Jodie Burchell (original code).

1. [`1.data-exploration.ipynb`](1.data-exploration.ipynb) – Data cleaning
2. [`2.vector-search.ipynb`](2.vector-search.ipynb) – Vector database for semantic search
3. [`3.text-classification.ipynb`](3.text-classification.ipynb) – Zero-shot classification into fiction / nonfiction
4. [`4_sentiment_analysis.ipynb`](4_sentiment_analysis.ipynb) – Emotion extraction from descriptions
5. [`gradio-dashboard.py`](gradio-dashboard.py) – Gradio dashboard
   
Tech Stack
Python, pandas, LangChain, Chroma, OpenAI Embeddings, Hugging Face Transformers, Gradio

Data
[7k Books with Metadata](https://www.kaggle.com/datasets/dylanjcastillo/7k-books-with-metadata) (Kaggle)
